# Tamiya Paint Conversion Chart (GitHub Pages)

Интерактивная таблица соответствия акриловых модельных красок Tamiya (X / XF) краскам других популярных производителей:
- **Revell** (Aqua / Email)
- **Vallejo** (Model Color / Model Air)
- **Mr.Hobby / Mr.Color** (Aqueous / Lacquer)
- **AMMO Mig Jimenez**
- **Humbrol**
- **Hataka**
- **Lifecolor**
- **Mission Models**
- **Testors / Model Master**

## 🌐 Как работает сайт
Сайт построен на чистом HTML5/CSS3/JavaScript без внешних сборщиков и готов к автоматической публикации через **GitHub Pages**.
Включает:
- Живой мгновенный поиск по коду и названию.
- Быстрые фильтры (Матовые XF, Глянцевые X, Металлики, Прозрачные).
- Цветовые плашки (Color Swatches) для каждого оттенка.
- Экспорт всей базы в CSV.
